## Already built into every page
- One H1 per page (in the hero), H2 sections, H3 cards
- Focus keyword in H1, first paragraph and an image alt
- JSON-LD schema: Electrician (Home, Contact), Service (service pages), CollectionPage + Electrician (location pages), Article (case studies)
- Internal links: every service links to related services, Contact and the area pages; every location links back to the services
- Area chips on Home, About and Services link to every location page (hub-and-spoke for local SEO)
- Phone shown the same everywhere: 07742 924814 / tel:07742924814
- Descriptive image filenames and alt text (see IMAGES-NEEDED.md)

## The biggest ranking wins outside the website
1. **Google Business Profile** - make sure the website link points to https://www.jwelectricalinstalls.com/ and categories include "Electrician". This drives most local "electrician near me" results.
2. **Reviews** - ask every happy customer for a Google review. Only one testimonial is on the site so far.
3. **Search Console** - connect via Site Kit, submit `sitemap_index.xml`, and use URL Inspection > Request indexing for every page after launch.
4. **Old Wix URLs** - once the domain points at Hostinger, add 301 redirects in Rank Math > Redirections:
   - `/about-3` -> `/services/`
   - `/contact-7` -> `/contact-us/`
   - `/privacy-policy` already matches
5. **Directories** - consistent name, phone and area on Checkatrade/Bark/Yell etc. if he uses them.

# J.W Electrical Installations - Website

New WordPress site for J.W Electrical Installations (James Watton, Poole), built from the KJM trades-site blueprint.

- `pages/` - one file per page, paste into a single Custom HTML block
- `wordpress/` - child theme zip, theme CSS, footer widgets
- `SETUP.md` - step-by-step build checklist
- `SEO.md` - Rank Math title, description and focus keyword per page
- `IMAGES-NEEDED.md` - every image filename and what it's for
- `src/` - generator; edit `src/config.py` or the `data_*.py` files, then run `python3 src/build.py`
